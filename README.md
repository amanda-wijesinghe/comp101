# comp101
Description: This README file is meant to introduce the project (in this case lab 2) that is being presented and to convey important information and instructions to the reader/user.
Purpose: The purpose of this lab was to familiarize yourself with the GitHub website and to practice creating a repository. A repository is like a digital storage folder, where one can store and organize files and code for a project. Repositories can be private or public, and may have multiple collaborators working on it. 
Lab Instructions: The instructions for this lab was create a GitHub account, add/write this current README, and create a 'lab 2' folder with a .txt file that contains the hardware specifications to one's current computer. After the completing the README and .txt file, to save each file to the repository one must click 'commit changes'. 'Commit changes' will prompt one to write a brief description on what the file contains, or any changes that have been made since it was last saved.
